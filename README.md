## Browser Extensions

Install these extensions:

- 1Password
- uBlock Origin Lite
- Hush Nag Blocker (iPhone, blocks cookie banners in Safari)

Block those annoying cookie banners in Chrome on desktop by going into Settings for the uBlock Origin Lite extension and do the following:

- Click the uBlock Origin extension icon and open the Dashboard (gear icon).
- Go to the Filter lists tab.
- Expand the Annoyances section.
- Check EasyList Cookie and/or uBlock features – Annoyances.
- Click Apply changes.
